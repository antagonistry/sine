# SINE Language

## Sypnosis.

SINE **[SINE's Not Exponent]**
is an interpreter that can be used to
calculate cells and counters dynamically.

## Why SINE?

SINE is a **very light-weighted interpreter**
and is blazingly fast, and no artificial
intelligence have been used.

## Installation Guide.

### First Step:

```sh
git clone \
https://github.com/antagonistry/sine.git
```

### Second Step:

```sh
cd sine && ./build.sh
```

## Can I Embed SINE in my Program?

It is pretty easy to do that, you can just
directly included the SINE's source file!
